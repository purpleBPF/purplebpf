A · 프로세스 트리 (추론)

선택된 라운드의 각 step command를 파이프/구분자 기준으로 쪼개 부모-자식 형태로 보여줍니다.

라운드를 선택하세요
⚠️ 이 트리는 실제 프로세스 fork/exec 관계(syscall 트레이스)가 아니라, command 문자열을 ; / && / || / | 기준으로 정규식 분리해 추론한 것입니다. 쉘 인용부호·서브셸·변수 치환까지 완벽하게 파싱하지 않으므로 참고용으로만 사용하세요.

B · 단계 흐름

validator level1(문법) 기준 step 목록과 실제 실행 결과(있는 경우)를 순서대로 표시합니다.

라운드를 선택하세요

C · 라운드 결정 분포

불러온 최근 라운드 전체 기준 판정 분포입니다.

데이터 없음
